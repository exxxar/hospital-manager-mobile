# МедПерсонал — Android

## Старт приложения

При каждом запуске сначала открывается экран выбора режима:
- **Демо-режим** — локальные данные, без HTTP-запросов.
- **Сервер клиники** — доступен только если в сборку передан корректный `API_BASE_URL`.
- **Открыть отладчик** — доступен до выбора режима.

## GitHub Actions

1. Загрузите всё содержимое архива в корень репозитория.
2. Откройте Actions и запустите workflow `Android CI` (или сделайте push в `main`/`master`).
3. Скачайте артефакт `clinic-staff-debug-apk`.

## Переменные GitHub

Для автономного DEMO-режима переменные не нужны.

Для серверного режима создайте **Settings → Secrets and variables → Actions → Variables**:

- `API_BASE_URL` — полный базовый URL Laravel API, например `https://clinic.example.org/api/v1/`.

Требования: HTTPS, путь `/api/v1/` и завершающий `/`. Не добавляйте сюда пароль или токен. Значение попадёт в APK и не является секретом.

Если `API_BASE_URL` пустой, приложение собирается автономно, а сетевой interceptor блокирует HTTP-запросы.

## Диагностика сборки

Workflow сохраняет артефакт `android-compiler-log` даже при ошибке компиляции. В нём будут исходные сообщения Kotlin вида `e: file:///...:line:column`, а не только общий стек Gradle.
